## How I build

1. **Understand the operation first.** I map the real workflow and its constraints before choosing the implementation.
2. **Design for failure.** Background jobs, external integrations and AI calls need validation, retries and safe fallbacks.
3. **Keep contracts explicit.** Shared schemas and structured outputs reduce ambiguity between services and interfaces.
4. **Ship with evidence.** Automated tests, smoke checks and production monitoring are part of delivery, not an afterthought.
